## 1. What the paper is

**Method: replica + Gaussian-equivalence analysis of the ERM (global-minimiser) solution, plus a
rigorous population-limit theorem. No pretraining dynamics anywhere** (no GD/SGD, no time, no fixed-point
stability of a training flow; "fixed point" always means the replica saddle point). Search of the full text
for dynamics/gradient/exponent/information exponent/stable/emergence: only hits are citations to other work
and the replica saddle point.

- p.5: "The results are derived using the replica method together with a Gaussian-equivalence ansatz, in
  which the local fields are replaced by Gaussian variables with matching leading-order covariances. ... In
  our ICL setting, however, we use it as an ansatz and validate the resulting predictions numerically."
- p.1 (intro): "Other works also study the learning dynamics of ICL [34, 39] ..." (cited, not done).

### Data model (p.2-3)
- Inputs and task vectors uniform on the sphere of radius sqrt(d); finite pool of N0 tasks
  "a_k i.i.d. ~ Unif(S^{d-1}(sqrt d))"; per prompt "a^mu := a_{tau_mu} with tau_mu i.i.d. ~ Unif({1,...,N0})".
  Isotropic prior on the index direction, no task mean, no low-rank structure ("We do not consider the
  distribution shift here because this is not our main focus", p.3).
- Labels (eq. 1, p.3): "y = sigma_star((a^mu)^T x / sqrt d) + eps, eps ~ N(0, Delta)".
- **Information exponent fixed to 1**, p.3: "sigma_star ... satisfying E[sigma_star(G)] = 0,
  E[sigma_star(G)^2] = 1 and mu_1 := E[sigma_star(G)G] != 0 ... While the first two assumptions are imposed
  for simplicity, mu_1 != 0 is essential. It guarantees a nonvanishing linear component of the teacher and
  places the problem in the O(d^2) learning regime [31]."
- Noiseless labels at inference (p.3). Memorisation error E_M (test task from pool) vs generalisation
  error E_G (fresh task), eq. (2).

### Kernel learner (p.4)
- Fixed feature map h (concatenated spherical harmonics of degrees in a finite set K), then linear
  attention: eq. (6) "y^ = Tr(W (H^K)^T), H^K := (1/L) h(x0) (sum_l y_l h(x_l))^T"; trained by ridge ERM,
  eq. (7). "training the attention layer is equivalent to a linear regression problem in the D^2 entries".

### Feature learner (p.4-5) -- what exactly it is
- Linear attention on raw inputs, eq. (9): "u_W = (1/L) sum_l y_l (x0)^T W x_l"; i.e. a **d x d bilinear
  form W, linear in the labels**. There is **no hidden neuron / index direction w and no sigma(w.x)
  feature**; "feature" = W.
- **Yes, a learned nonlinear scalar readout**, applied AFTER attention: p.5 "The final prediction is
  obtained by applying a scalar nonlinear readout y^ = sigma(u_W)."
- **Two-stage, decoupled training** (p.5): "In the first stage, we fix a prescribed scalar function sigma_0
  and optimize only the attention matrix" (eq. 11) ... "Here sigma_0 is fixed throughout the first stage and
  is not itself trained." "In the second stage, we freeze W^F and optimize only the scalar readout"
  (eq. 12), on fresh prompts of the **training** length L; "The solution of (12) is
  sigma^(u) = E[y0 | U = u, W^F, A0]." Readout is idealised as population-optimal ("we idealize its
  estimation error away by taking N' -> infinity and N'/N -> 0").
- In Theorem 1 and all scaling results sigma_0(v) = v (identity), so Stage I is a convex quadratic.
  Experiments (p.7): "fix the scalar readout to sigma_0(u) = u by initializing a width-64 ReLU readout
  (which remains frozen during Stage I), and do full-batch L-BFGS."
- **The readout never feeds back into the learning of W** (Stage I uses fixed sigma_0).

### What is trained vs analysed at inference
- Trained: W (ERM / population minimiser) at training length L; then sigma^ at training length L.
  Analysed at inference: the same frozen (W, sigma^) applied to prompts of length L~.
- p.7: "There is a nonnegative mismatch error (the third term of Eq. (21)) for the feature learner which
  arises because the Stage-II readout is optimized for the training context length L and is then kept
  fixed at inference."

### How L and L~ enter
- Limits: alpha_K = L/D, alpha~_K = L~/D (kernel), alpha_F = L/d, alpha~_F = L~/d (feature), p.5-6.
- Kernel error, eq. (15), p.6: "E^kernel_P ~ nu_out + nu_in(1 - 2m_{K,P} + q_{K,P}) + q_K / alpha~_K".
- Feature learner: L enters W via tau = (1+Delta)/(alpha mu_1^2) and the Stage-II readout; L~ enters the
  test variance V_M = mu_1^2 q + q~/alpha~ (eq. 19/171).
- Rigorous population theorem: Appendix D, Theorem 2 (p.41-42); Assumption 4 (p.41) requires
  "c <= L/L~ <= C, min{L, L~} >= d^epsilon".

## 2. Context-length threshold statements (d^k vs d) -- verbatim

- p.2 (contributions): "For a kernel learner containing degree-k spherical harmonics, recovering that
  component requires a context length of order d^k, which produces a stage-wise learning curve. By
  contrast, the feature learner exhibits a single transition at L = Theta(d) and can exploit all Hermite
  components of the teacher at the same time. We also rigorously characterize the behavior when the
  training context length and the test contest length are different."
- p.6, Theorem 1 (Informal): "Take kappa_F, kappa_K -> infinity after gamma_F, gamma_K -> infinity, and set
  Delta = lambda = 0 and sigma_0(v) = v. ... For the kernel learner, define eta_{k,L} := c_k^2 L /
  (D_{k,d} + c_k^2 L). Then ... E^kernel_P = nu_out + sum_{k in K} [ c_k^2 (1 - eta_{k,L})^2 + (D_{k,d}/L~)
  eta_{k,L}^2 ] + o(1). (20) For the feature learner, define rho_alpha := c_1 / sqrt(c_1^2 + 1/alpha),
  r_alpha := rho_alpha^2 and s_{alpha,alpha~} = rho_alpha / rho_alpha~. Then E^feature_P = 1 - sum_k c_k^2
  r^k_alpha~ + sum_l ( A_l(alpha, alpha~) - c_l rho^l_alpha~ )^2 + o(1) (21)" [A_l written out in eq. 21/208].
- p.7, eq. (22): with L = L~ = alpha d^s, E^feature -> 1 for 0<s<1; 1 - sum_k c_k^2 r_alpha^k for s=1;
  0 for s>1.
- p.7: "This suggests that for the kernel learner, a degree-k harmonic sector is asymptotically fully
  recovered when L >> d^k, is only partially recovered when L = Theta(d^k), and is asymptotically unrecovered
  when L << d^k. Moreover, assuming s = 1 and 1 in K, we obtain E^kernel - E^feature ~ sum_{k>=2} c_k^2
  r^k_alpha. For a nonlinear teacher this gap is strictly positive for every alpha > 0."
- p.7: "For the kernel learner, a degree-k spherical-harmonic sector requires a context length of order d^k
  to be recovered. Under L = Theta(d), only the degree-one sector contributes. By contrast, the feature
  learner only requires L = Theta(d) demonstrations and exploits all Hermite components of the teacher with
  factors r^k_alpha simultaneously."
- p.7: "On the other hand, the kernel learner has an advantage that a longer inference context always
  improves its performance by Eq. (20). In contrast, such monotonicity need not hold for the feature
  learner." ... "Theorem 1 also implies that when L~ is fixed, both the kernel and the feature learner reach
  the optimal performance at L = L~. Increasing the training context beyond L~ is not beneficial."
- p.24, after eq. (120): "Hence a degree-k harmonic component is asymptotically fully recovered when
  L >> d^k, partially recovered when L = Theta(d^k), and unrecovered when L << d^k."
- p.36, eq. (215): r_alpha(d) = alpha c_1^2 d^{s-1} / (1 + alpha c_1^2 d^{s-1}) -> 0 (s<1), r_alpha (s=1),
  1 (s>1).
- p.9-10 (Fig. 4): "The kernel learner acquires the degree-one and degree-two components at the separate
  scales L ~ d and L ~ d^2, whereas the feature learner recovers both components at the same time."
- Pretraining-size thresholds (number of prompts, not context) p.7: "The feature and kernel attention
  matrices contain d^2 and D^2 = Theta(d^{2p}) parameters, respectively, and hence converge on the scales
  N >> d^2 and N >> D^2." Corrections O(d^2/N), O(D^2/N) (eqs. 113, 198). Interpolation peaks near
  N ~ d^2, N ~ D^2 (p.8).

All of these are thresholds for **in-context estimation by the converged learner** (SNR of the
in-context statistic, rho_alpha), with training-length and inference-length thresholds coinciding
(r_alpha). None is a threshold for whether a feature is acquired during pretraining dynamics.

## 3. Shrinkage of the trained attention / readout (relevant to C3) -- verbatim

The Wiener-type factor signal/(signal + noise/L) **does appear explicitly**, as the closed-form
population/ERM optimum (not as a dynamical effect):

- Feature learner Stage I, p.46, eq. (298): "the risk is strictly convex and has the unique minimizer
  W^F_{d,L} = w_{d,L} I_d, w_{d,L} := L mu_d^2 / (d v_d + (L-1) mu_d^2). In particular, w_{d,L} > 0."
  [= (mu^2/d) / ((mu^2/d)(1-1/L) + v/L): exactly our Gamma* = g^2/(g^2(1-1/N) + V/N) with V = v_d = E[y^2]
  isotropic and N -> L.] Population risk eq. (297): "R_{F,L}(W) = v_d - (2 mu_d^2/d) Tr(W) + ((L-1)/L
  mu_d^2/d + v_d/L) ||W||_F^2."
- Kernel learner, p.45: "W^K_{d,L} acts on this block as multiplication by w_{k,d,L} := L c_{k,d}^2 /
  (v_d D_{k,d} + (L-1) c_{k,d}^2)"; eq. (281) "W^K_{d,L} = M_d A^{-1}_{d,L}"; eq. (276) "A_{d,n} :=
  (n-1)/n M_d + v_d/n I_D".
- Replica large-pretraining limit, p.34 eq. (186): "W_infinity := S(S + tau I_d)^{-1}", tau := (1+Delta)/
  (alpha mu_1^2); p.36 eq. (200): "W_infinity -> r_alpha I_d, r_alpha := alpha mu_1^2/(1 + alpha mu_1^2)".
  Kernel analogue eq. (104): "W_{K,infinity} := S_K (S_K + b_K I_D)^{-1}", b_K = (1+Delta)/alpha_K.
- Stage-II readout, eq. (18) p.6 / eq. (176) p.33: sigma^(v) = E_psi[ sigma_star( mu_1 m / (mu_1^2 q +
  (1+Delta) q~/alpha_F) v + sqrt(1 - mu_1^2 m^2/(mu_1^2 q + (1+Delta) q~/alpha_F)) psi ) ] -- conditional-mean
  (Bayes) readout with an SNR-dependent shrinkage of its argument; p.36 eq. (204): "By Mehler's identity,
  the optimal Stage-II readout is sigma^_alpha(v) = sum_{k>=1} c_k rho^k_alpha H_k( v / (r_alpha B_alpha) )."

**Not present**: any statement that this shrinkage changes an information exponent, slows/accelerates
pretraining feature learning, or a crossover d ~ L^{1/k*} for pretraining. (Formally the kernel-sector
crossover L ~ D_{k,d} ~ d^k <=> d ~ L^{1/k} has the same scaling as our C3 crossover, but it is the
in-context estimation threshold of a fixed-feature learner, k ranges over harmonic degrees of the target,
and there is no exponent change.) The words "information exponent" never occur.

## 4. Alignment-dependent variance of the in-context statistic (relevant to C2) -- verbatim

The alignment-dependent fourth-moment term is **identified and then discarded** (treated as lower order /
replaced by its isotropic average). It never enters a loss landscape over a student direction.

- p.18, eq. (62)-(66): "E[H^K_ij H^K_i'j' | a] = delta_ii' [ (L-1)/(LD) theta_j(a) theta_j'(a) + (1/L)
  B_jj'(a) ], where B(a) := E_x[y^2 h(x) h(x)^T | a]. ... Moreover, rotational invariance gives
  E_a[B(a)] = (1+Delta) I_D. Conditioned on a, however, B(a) is not asymptotically isotropic.
  Nevertheless, for the following we replace B(a) with its expectation (i.e., a self-averaging ansatz)".
- p.26, eq. (128) (feature learner): "E[y^2 x x^T | a^mu] = (1+Delta) I_d + O(1) a^mu (a^mu)^T / d + o(1)";
  in eq. (131) only the isotropic part survives: "E[u^r u^s | a] = (mu_1^2/d)(W^r a)^T (W^s a) +
  (1+Delta)/(alpha d) Tr(W^r (W^s)^T) + o(1)."
- p.48, eq. (312) (rigorous part): "the conditional covariance of eta is Gamma_d(a) := E[eta_1 eta_1^T | a] =
  (t_d - mu_d^2) e e^T + beta_d (I_d - e e^T), where t_d = E[sigma_star(G_d)^2 G_d^2] and beta_d =
  (d v_d - t_d)/(d-1)." Used only to prove concentration of the context statistic (Lemma 2, p.47).
- In the population theorem the alignment dependence is averaged out because a is integrated jointly:
  p.44 eq. (277) "E_{a,x}[y^2 h(x) h(x)^T] = v_d E_x[h(x) h(x)^T] = v_d I_D"; p.46 eq. (294)
  "E[y^2 x x^T] = v_d I_d".
- The only "short context kills the learned model" statement is the scalar shrinkage above: w_{d,L} -> 0,
  r_alpha -> 0 when L << d, so E^feature -> 1 (eq. 22). This is a convex optimum continuously going to 0,
  not a stable unaligned fixed point, and it is the same threshold as in-context estimation.

## 5. Squared link / squared coefficients (relevant to C1)

Squared teacher coefficients appear as the "signal" in the quadratic pretraining objective, as an
algebraic fact, without interpretation:
- p.46, eq. (295): "E[y0 x0 V^T_{d,L}] = E_a[ E[y0 x0|a] E[V_{d,L}|a]^T ] = mu_d^2 E_a[e e^T] = (mu_d^2/d) I_d."
- p.44, eq. (275): "M_d := E_a[m_d(a) m_d(a)^T] = (+)_{k in K} (c_{k,d}^2 / D_{k,d}) I_{D_{k,d}}"; eq. (280)
  "R_{K,L}(W) = v_d - 2 Tr(W M_d) + Tr(W A_{d,L} W^T)".
- p.3: mu_1 != 0 "places the problem in the O(d^2) learning regime [31]".
No student neuron direction w, no alignment polynomial, no "link squared"/"effective exponent 2k*"
statement; k* = 1 is assumed throughout so the question of 2k* vs k* cannot arise.

## 7. Stated open problems / limitations (verbatim)

- p.10 (Conclusion): "Several directions remain open. Our analysis focuses on one-layer linear attention,
  spherical-harmonic features, and an idealized two-stage training procedure in which the scalar readout is
  learned from sufficient additional data. It would be useful to understand whether the same separation
  persists for random features or learned embeddings, jointly trained readouts, softmax attention, and
  deeper Transformer architectures. On the theoretical side, important directions include proving the
  finite-dimensional results and analyzing ICL beyond single-index targets with mu_1 != 0."
- p.4: "This spherical-harmonic construction should be viewed as an analytically convenient realization of
  a fixed nonlinear feature map. More practical embeddings, such as random features [20, 1, 9], lead to
  closely related architectures. We leave the analysis of such random-feature learners to future work."
- p.3: "Related works have also studied in-distribution and out-of-distribution task generalization by
  restricting the task vectors to lower-dimensional subspaces [35, 24]. We do not consider the distribution
  shift here because this is not our main focus."
- p.5: "Such Gaussian equivalence has been established rigorously for several related models [18, 19, 29].
  In our ICL setting, however, we use it as an ansatz and validate the resulting predictions numerically."
- p.15: "The residual r_{K,d}(a,x), however, is in general neither Gaussian nor independent of h(x). To
  obtain a tractable effective model, we make an additional Gaussian-equivalence approximation".
- p.18: "Conditioned on a, however, B(a) is not asymptotically isotropic. Nevertheless, for the following we
  replace B(a) with its expectation (i.e., a self-averaging ansatz)".
- p.29: "This scaling holds for a strictly convex quadratic objective, as in the identity-readout case with
  lambda > 0; for a general sigma_0, finite limits of these scaled differences are part of the ansatz [23]."
- p.8: "The feature learner, linear attention and kernel learner all show the familiar double-descent
  behavior [24] ... Stage II substantially reduces the interpolation peak for the feature learner, although
  a smaller peak remains." p.37: "with visible deviations near the kernel interpolation peak."
- Note (ours): "jointly trained readouts" being listed as open is consistent with C3's dynamical part being
  new; "beyond ... mu_1 != 0" (i.e. k* >= 2) being open is consistent with C2 (which lives at k* >= 2) being new.
