# 研究メモ（日本語、人間の著者が framing を判断するためのもの）— 2026-10-09

## 問い
additive model `y = Σ_p c_p σ(⟨v_p, x⟩)` のスキルを **in-context** で提示したとき（タスク係数 `c_p` は平均ゼロ、文脈長 `N` のプロンプトから
特徴 `v_p` を online SGD で学ぶ）、スキル獲得の emergence 時刻を支配する指数は何で決まるか。既存理論は文脈長を推論時の資源として扱い、
one-step 解析ではプロンプト数とプロンプト長は積でしか効かない（Oko et al. 2024, Remark 3）。

## 答え（可解モデルで確定、SGD で定量確認）
1. **リンクの2乗**：`N→∞` で in-context 損失は in-weight 損失の `g→g²` 置換。有効指数 `2k*`。→ Oko Lemma 21 に暗黙に含まれる（機構として引用）。
2. **有限文脈項 `Γ²V(m)/N`** は整列とともに増える。この項の効果は**読み出しのパラメータ化で3通り**に分かれる：
   - 固定 O(1) 読み出し：`m < m*` で原点が drift 安定 → **罠**（プロンプト数を増やしても解けない；SGD では軟らかい）
   - 自由スカラー読み出し：Wiener 値へ縮み、有効指数 `2k*→4k*`、**乗法的 N–T トレードオフ**（断熱極限で `τ ∝ 1/N`；実験パラメータでは
     成長律速で中間的、`T(16)/T(256) = 4.4`、ODE 一致）→ Oko Remark 3 はこの場合として回収される
   - 結合読み出し（Ren et al. の 2-homogeneous）：方向の力学がノルムに依らず **N 非依存**；`ρ₀ ≳ N m₀²/4` では罠でなく**遅延**（Exp 7 で判明）
3. **母集団 ODE（自由パラメータなし、実行前に固定）が SGD を再現**：κ_eff 12 セル全て 0.49 以内（Tobit）、Exp 6 の 18 セル全て 15% 以内。
4. 多スキル：`T_p ∝ 1/π_p`（傾き 1.44–1.53 vs 予測 1.5）、in-weight の 0.75–0.89 の約2倍急。加法合成はラベル線形性による恒等式で無料。

## 新規 vs 既知（全文照合 16 本）
| 事項 | 既知 | 我々 |
|---|---|---|
| `m^{2Q−1}` 勾配 | Oko Lemma 21、Nishikawa Lemmas 20–21 | 動的解釈、online SGD の時間尺度、k*=2 regime |
| 速い読み出しによる指数倍化（in-weight） | BBPV 2023 §5、BBSS 2022 eq.(12) | in-context 版：有限文脈ノイズが読み出しを縮める |
| 静的 shrinkage 公式 | Gu–Xu–Zdeborová eq.(297)–(298) | その動的効果、`N` クロスオーバー、パラメータ化依存 |
| 有限 n で原点が局所最小になりうる | Kim–Suzuki App. C.4（定性的） | 機構・条件 `m*`・SGD での軟化・N–T 非交換 |
| 方向力学のノルム非依存 | Ren Lemma B.1 | その帰結（N 非依存、罠→遅延） |
| 乗法的合成 | Okawa（定義）、Arora–Goyal（追加遅延） | 恒等式＋閾値による近似的乗法性；追加遅延なし |

## 失敗・訂正（全て記録済み）
- 事前登録の誤り：κ=1 の `d^{1.5}` 予測、閾値式の因子2、Exp 3 の推定量（床・独立評価セット）、Exp 1b の「硬い閾値」、P20d「反発は結合でも生き残る」。
- Transformer：Exp 4（d=32・幅256）は逆方向の N 依存；Exp 5（d=256・幅32）は「罠でも交換可能でもなく約3倍の handicap」。Exp 8（読み出しを
  凍結/縮小した場合）が転移の最後の検定。
