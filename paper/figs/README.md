# Paper figures

Regenerate with `python3 -I paper/figs/make_figs.py` (from `/home/user/ml`; reads `results/`, writes only here).
Each figure is a vector PDF (fonts embedded, Computer Modern text and math, 8.5 pt base size in every figure) plus a 200-dpi PNG preview.
Palette: reference categorical slots blue `#2a78d6`, orange `#eb6834`, aqua `#1baf7a` (and violet `#4a3aa7`), checked with
`validate_palette.js --pairs all` (pass; aqua is below 3:1 contrast on white, so every series is also identified by a legend entry or marker shape, never by colour alone).
Figures are drawn at print size; include at the native width so fonts stay at 8-9 pt:
`fig_kappa.pdf` 4.1 in (about `.63\linewidth`), the other three 6.2-6.4 in (`\linewidth` or `.97\linewidth`).
